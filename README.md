# Как запустить базу
1. Запустите «1С:Предприятие» (ярлык запуска 1С, обычно называется 1C:Enterprise или 1cv8).
2. В открывшемся окне выберите вариант «Создание новой информационной базы» и нажмите «Далее».
3. Выберите пункт «Создание базы без конфигурации...» (чтобы развернуть чистую базу под вашу конфигурацию) или из шаблона (если устанавливаете типовую конфигурацию).
4. Введите наименование базы (произвольное имя, которое будет отображаться в списке).
 
   Загрузка полной информационной базы (.dt)
1. В списке баз запустите созданную базу в режиме «Конфигуратор».
2. В верхнем меню выберите Администрирование -> Загрузить информационную базу...
3. Выберите файл резервной копии с расширением .dt и нажмите «Открыть».
4. Подтвердите выполнение операции (система предупредит, что текущие данные будут перезаписаны).
5. Дождитесь сообщения об успешной загрузке и закройте Конфигуратор.
